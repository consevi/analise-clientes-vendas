Projeto de análise de clientes e vendas utilizando SQL, Excel e Python.

# Análise Estratégica de Clientes e Vendas

## Objetivo

Analisar o perfil dos clientes, comportamento de compras,
faturamento e relação entre renda e consumo.

## Tecnologias

- SQL
- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## Estrutura

sql/ → consultas SQL
python/ → análise em Python
excel/ → dashboard
graficos/ → visualizações
dados/ → bases utilizadas
